# 设备质检 · 风险评分分箱分析页

离线单页应用：直接用浏览器打开 `index.html` 即可，数据不离开本机，无任何外部依赖。

## 功能

- **数据导入**：演示数据（36 个不同评分，≤ 40）/ CSV 文件 / 粘贴 CSV 文本 / 下载模板。
  列为 `score, defect, weight, batch`（支持中文表头：评分、是否发现缺陷、样本权重、生产批次；
  缺陷接受 0/1、是/否、true/false；评分留空或 `NA`/`缺失` 视为缺失）。
- **单调最优分箱**：相同评分先聚合（绝不拆到两组），缺失评分单独统计、不参与数值顺序。
  在「每组最低样本权重 + 最大分组数 + 组缺陷率单调不降」约束下，用**动态规划**求整体损失
  （组内加权平方误差 / 行级加权 Brier 损失）最小的全局最优切分——不是贪心相邻合并。
- **锁定业务边界**：输入边界值 B，强制「≤ B」与「> B」分开成组，页面显示它使最优损失
  增加了多少；若锁定后没有满足限制的切法，会明确说明原因。
- **训练/评估按生产批次分开**：分箱边界只在训练批次上决定；评估样本按固定切点落组，
  约定**左闭右开** `[a, b)`，切点取相邻组训练评分的中点，首末组外端开放。
- **组详情**：点击图表或表格中的组，查看真实缺陷台数、权重、来源批次明细与置信区间。
- **稳定性检查**：高分段（末组）样本不足、评估集无样本/样本少、置信区间过宽会给出
  明显标记；评估集缺陷率出现回落也会提示。
- **不输出设备安全承诺**：所有结果仅用于安排复查优先级。

## 核对

```bash
node verify-binning.mjs      # 500 组随机小样本：动态规划 vs 穷举全部切分，比对可行性与最优损失
node test-page-smoke.mjs     # 最小 DOM 桩下执行页面逻辑，冒烟验证主要交互路径
```

页面内「6 · 方法与自测」也提供同样的穷举核对按钮（每次随机种子）。

## 方法说明

- 损失：组 g 的损失 = `D − D²/W`（W 为组权重和，D 为组加权缺陷和），即各行缺陷指示
  相对组缺陷率的加权平方误差之和；总损失为各组之和。
- 单调：组缺陷率沿评分单调不降（允许持平）。
- 动态规划状态：`dp[g][s][t]` = 前 t 个评分分成 g 组、末组恰为 `[s..t]` 的最小总损失，
  转移时要求前一组均值 ≤ 本组均值；锁定边界等价于禁止任何组跨越该切点。
- 置信区间：按权重折算的 Wilson 近似区间，仅用于判断估计稳定性。
